# Structured rules own disposal decisions

Because disposal guidance varies by jurisdiction and effective date, a retrieval-first model answer could let stale or adjacent source text determine the action. Use reviewed, jurisdiction- and item-specific rules as the sole action authority; source-linked Knowledge Base passages support those rules, and Jev may supply only a bounded fact before deterministic resolution runs again. This is less flexible than free-form model advice, but keeps decisions auditable and fail-closed.
